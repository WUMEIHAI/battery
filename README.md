# 用电量与电费计算器

一个纯前端、单文件的在线计算器：输入电器功率、每天使用时长和电价，一键算出指定周期内的**用电量（度）**与**电费（元）**。

- **项目类型**：静态网页（HTML + CSS + 原生 JavaScript）
- **入口文件**：`index.html`
- **依赖情况**：无任何第三方库、无构建步骤、无后端接口
- **运行方式**：双击 `index.html` 用浏览器打开即可

---

## 项目简介

日常想知道"这台电器一天/一个月/一年要花多少电费"，手算需要先把瓦换算成千瓦，再乘以时长、天数、电价，步骤琐碎还容易算错。

本项目把这套换算封装成一个极简表单：填 4 个字段，点一次按钮，直接给出用电量和电费。所有计算都在浏览器本地完成，**不上传任何数据，也不联网请求**。

核心公式（1 度电 = 1 千瓦时）：

```
用电量（度） = 功率（kW） × 每天使用时长（h） × 计算周期天数
电费（元）   = 用电量（度） × 电价（元/度）
```

> 注意：目录名为 `battery`，但实际功能是**市电用电量与电费计算**，与电池（Battery）无关。目录名保留原样，未做改动。

## 功能说明

### 输入项

| 字段 | 控件 | 说明 | 默认值 |
|---|---|---|---|
| 电器功率 | 数字输入 | 支持小数，必须大于 0 | 空（占位示例 `1500`） |
| 功率单位 | 下拉选择 | `瓦 (W)` / `千瓦 (kW)`，自动换算 | 瓦 (W) |
| 每天使用时长 | 数字输入 | 单位小时，范围 **0 ~ 24**，支持小数（如 1.5 小时） | 空（占位示例 `24`） |
| 计算周期 | 下拉选择 | 一天 / 一个月（30 天）/ 一年（365 天） | 一天 |
| 电费单价 | 数字输入 | 单位 元/度，步长 0.01，不能为负 | `1.2` |

### 输出结果

计算成功后，结果区展示两行：

- 📊 **用电量** —— 单位「度电」（kWh）
- 💰 **电费** —— 单位「元」，带 `¥` 符号

数值格式化规则：绝对值 ≥ 1 时保留 **2 位小数**，< 1 时保留 **4 位小数**（避免小功率短时使用的结果被四舍五入成 0.00）。

### 输入校验

| 情况 | 提示 |
|---|---|
| 任一必填字段为空或不是有效数字 | ⚠️ 请输入完整的数值！ |
| 功率 ≤ 0 | ⚠️ 功率必须大于 0！ |
| 每天使用时长 < 0 或 > 24 | ⚠️ 每天使用时长必须在 0 - 24 小时之间！ |
| 电价为负数 | ⚠️ 电价不能为负数！ |

错误提示通过 `role="alert"` 播报，出现错误时结果区会重置为占位文案，**不会保留上一次的计算结果**。

### 主要特性

- **单文件零依赖**：HTML、CSS、JS 全在一个 `index.html` 里，无 npm、无 CDN、无打包，离线可用。
- **精度处理**：电费先用「分」为单位做整数运算（`Math.round`），再除以 100 转回元，规避浮点累加误差。
- **响应式布局**：`clamp()` + CSS Grid 自适应；窗口宽度 ≤ 420px 时双列自动堆叠为单列。
- **无障碍支持**：`aria-live="polite"` 结果播报、`role="alert"` 错误提示、`:focus-visible` 键盘焦点环、`sr-only` 隐藏文本类。
- **动效降级**：尊重系统 `prefers-reduced-motion` 设置，开启减弱动效时关闭入场动画与按钮位移。
- **SEO / 分享元信息**：内置 `title`、`description`、`canonical`、Open Graph 与 Twitter Card 标签。

## 使用方法

### 本地运行

直接用浏览器打开 `index.html` 即可，无需安装任何东西。

如果需要在局域网内用手机访问，或希望以 HTTP 协议运行（部分浏览器对本地文件的策略更严格），可在目录下起一个简易服务：

```bash
# Python 3
cd D:\battery
python -m http.server 8000
# 然后访问 http://localhost:8000

# Node.js（需已安装 serve）
npx serve .
```

### 部署上线

把 `index.html` 上传到任意静态托管（GitHub Pages、对象存储、Nginx、Vercel 等）即可，**不需要构建**。

### 操作示例

以一台 **1500 W** 的取暖器、每天开 **8 小时**、电价 **1.2 元/度**、计算**一个月（30 天）**为例：

1. 电器功率填 `1500`，单位保持「瓦 (W)」
2. 每天使用时长填 `8`
3. 计算周期选「一个月（30 天）」
4. 电费单价保持 `1.2`
5. 点击「开始计算」

得出：用电量 **360.00 度电**，电费 **¥432.00 元**。

（验证：1500 W = 1.5 kW，1.5 × 8 × 30 = 360 度，360 × 1.2 = 432 元）

## 注意事项

1. **占位元信息待替换**：`<link rel="canonical">` 与 `og:image`、`og:url` 等目前指向 `https://example.com/...`，正式上线前请改成真实域名和封面图地址（建议 1200×630）。
2. **「一个月」按 30 天估算**：为简化计算统一取 30 天，不是自然月实际天数；一年按 365 天，未考虑闰年。需要精确账目时请手动换算。
3. **结果为理论估算值**：模型假定电器以额定功率满负荷持续运行。实际中变频空调、冰箱等会启停或调功率，真实耗电通常低于该值；建议以电表或功率计量插座实测数据为准。
4. **未覆盖阶梯电价**：只支持单一固定电价。若当地执行居民阶梯电价或峰谷分时电价，需自行分段计算后累加。
5. **数据不保存**：页面刷新后输入内容会清空，没有做 localStorage 持久化；电价默认值 `1.2` 每次打开都会重置，可按需修改 `<input id="price">` 的 `value` 属性。
6. **浏览器兼容性**：使用了 `:focus-visible`、`clamp()`、`replaceChildren()`、CSS Grid 等较新特性，建议使用 Chrome / Edge / Firefox / Safari 的近两年版本。
7. **修改样式**：所有配色与圆角集中在 `<style>` 的 `:root` CSS 变量里（如 `--primary`、`--result-bg`），改主题色只需动这几个变量。

## 二次开发提示

- 计算主逻辑在 `<script>` 的 `calculate()` 函数里，改公式只动这一处。
- 结果行渲染由 `makeLine(icon, label, value)` 生成，想增加「碳排放」「月均日均」等输出，复制一行调用即可。
- 输入项通过 `id` 获取（`power` / `powerUnit` / `hours` / `timePeriod` / `price`），新增字段需同步补校验逻辑。
